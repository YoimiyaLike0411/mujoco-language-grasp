# 三个拓展方向的调研与选题依据

## 课程给出的边界（原文要点）

来源：`mujoco-grasp-assignment/docs/EXTENSIONS_AND_ACADEMIC_INTEGRITY_ZH.md`、
`docs/METHOD_TRACKS_ZH.md`、`docs/EVALUATION_AND_RUBRIC_ZH.md`。

- 拓展必须仍围绕**抓取/分拣 + 视觉闭环**，并且包含**感知—规划—执行**的完整闭环；
- 不接受纯世界模型/SLAM 等与抓取无关的单点研究，也不接受直接搬运已有投稿；
- 评分重心：可复现 10、架构 10、任务理解与决策 15、感知与几何 15、规划/IK/执行 15、
  闭环验证与恢复 15、实验与数据证据 15、报告与分工 5；
- 鼓励的加分项包括：跨 seed 隐藏评测、歧义澄清、失败后有效重规划、**VLA 延迟感知 action chunk**、
  安全门控、统计置信区间、可复现消融。

## 方向 1：VLA（视觉—语言—动作）

- **课程态度**：明确推荐路线之一（`METHOD_TRACKS_ZH` C），且"VLA 延迟感知 action chunk"是加分项。
- **硬约束**：需要**真实** VLA 权重或真实推理服务，不能用固定坐标/简单图像通道伪装。
- **可行性证据**：磁盘仅剩 3.9 G。OpenVLA-7B 权重约 14 G，放不下；π0（3B）同样超限；
  SmolVLA（约 0.45 B）勉强可放，但它面向特定机器人数据的后训练，
  在自建的 Panda + 桌面 MuJoCo 场景上零样本成功率接近 0，而课程周期内也拿不到可用的演示数据去微调。
  退一步只能做"用 VLM 输出动作块"的分层方案，但那和课程基线里的 VLM 服务高度重合，
  难以证明"课程周期内产生的新增实现"，且存在"偏离主题/搬运已有成果"的解释风险。
- **结论**：出彩度最高，可实现性最低，**不选**。

## 方向 2：移动与操作（狗背机械臂 / 轮臂）

- **资产齐全**：`google_robot`（轮式移动机械臂）、`hello_robot_stretch`（伸缩臂移动平台）、
  `trossen_vx300s`、`unitree_go1/go2/a1`、`google_barkour`、`anybotics_anymal_b/c`。
- **可实现变体**：轮式底盘 + 机械臂（"轮臂"），做"语言指定目标 → 移动到工位 → 抓取放置"，
  还能给出"固定基座不可达、移动后可达"的量化对照。
- **成本**：四足 + 机械臂需要行走控制（课程周期内不现实）；轮臂则需要重建移动相机下的目标定位、
  导航与底盘-机械臂协同，等于在现有闭环之外再造一套感知与规划。
- **结论**：出彩度高，但工作量与风险集中在"与本课程抓取闭环关系较远"的导航部分，**不是最优**。

## 方向 3：人形平台 / 灵巧手抓取

- **资产**：`wonik_allegro`（16 自由度四指手，**位置执行器**，控制接口与本课程一致）、
  `shadow_hand`、`unitree_g1`（人形，自带三指手）、`unitree_h1`。
- **可实现路径**：桌面场景、托盘、物体、相机全部保持不变，只把末端执行器从二指夹爪换成四指灵巧手。
  难点收敛在"抓取合成 + 多指接触控制 + 抓取验证"，正是课程评分表里"规划/IK/执行"与
  "闭环验证"两项的正面内容。
- **出彩点**：
  1. 多指手能完成二指夹爪做不到的事（抓取笼、抓后原地调姿）；
  2. 可以给出**同任务、同感知、同评测器，只换末端执行器**的干净消融对照；
  3. 抓取质量（接触数、指尖间距、抬升后滑移）是可量化的指标。
- **风险控制**：不做全身人形平衡控制（课程周期内不可控），先把"人形平台"的**手**这一侧做扎实；
  `unitree_g1` 上肢作为后续迁移目标。
- **结论**：**选定方向 3 → 灵巧手抓取**。

## 选定后的实现目标（本次要交付的成果）

在**不修改课程工程**的隔离目录里，实现：

1. 把 MuJoCo Menagerie 的 16 自由度灵巧手装到课程 Panda 法兰上（与课程同一物理参数、同场景）；
2. 自研手掌坐标系 DLS IK 与抓取笼（grasp cage）标定；
3. 抓取合成：按物体几何搜索闭合度/偏置，给出可执行的抓取参数；
4. 完整闭环：真实 SAM3 感知 → 抓取 → 搬运到托盘 → 放置后验证；
5. 与二指夹爪基线的对照实验与失败分类；
6. 演示视频与可复现文档。
